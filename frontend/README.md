# Интерфейс Ритма

React 18, TypeScript и Vite. Пять основных экранов: главная, расписание, задачи, отчёты и настройки. На телефоне используется нижняя навигация, на широком экране — боковая панель.

## Разработка

Сначала запустите backend и зависимости по [корневой инструкции](../README.md#запуск-за-несколько-команд).

```bash
npm ci
VITE_API_URL=http://localhost:8088/api/v1 npm run dev
# http://localhost:5173
npm test
npm run build
```

Нужен Node.js 22.18+ для тестов с TypeScript. В production frontend собирается в Docker и раздаётся nginx.

## API и сессия

`public/config.js` задаёт runtime-конфигурацию `window.__ENV__.API_URL`. Пустая строка означает same-origin `/api/v1`; для Docker значение формируется из `API_PUBLIC_URL` при старте контейнера. В разработке Vite проксирует `/api` на backend; адрес для прокси задаётся переменной процесса `VITE_API_URL`.

`src/api/client.ts` обрабатывает запросы, таймаут, кеш и refresh. Refresh-cookie — HttpOnly; при сетевой ошибке сессия не удаляется. Приоритеты загружаются отдельно от обычного списка задач.

## PWA и ресурсы

`public/sw.js` при сборке получает версию кеша и список хешированных JS/CSS. Оболочка и фоны кешируются; для API нужен интернет. Web Push требует HTTPS, поддержки браузера, разрешения пользователя и серверных VAPID-ключей. Локальный HTTP-стек предназначен для разработки; поведение push проверяется отдельно на поддерживаемом устройстве.

Дизайн использует три темы и WebP-фоны. Исторический HTML-прототип находится в `docs/archive/ui-prototype.html`; рабочий интерфейс — в `src/`.
