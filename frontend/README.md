# Ритм — frontend

React + Vite + TypeScript. Дизайн перенесён из `docs/index.html`, все мок-данные заменены на реальный API.

## Экраны и ТЗ

- Главная (U.9/U.6): задачи на сегодня, просрочки, ближайшие события, статистика дня, быстрые действия + навигация.
- Auth (U.7/U.8): регистрация (имя+почта+пароль), вход по **логину или почте** + пароль.
- Расписание (U.11): день/неделя, реальные даты, навигация, zoom, линия «сейчас», FAB «+» для событий, CRUD.
- Задачи (U.10): просмотр/создание/изменение/удаление, честная отметка в обе стороны, бейдж «Просрочена», фильтры, поиск, повторяемость daily/weekly/monthly/yearly (F.9).
- Отчёты (U.12/F.10): выполненные/невыполненные/процент + счётчик событий, день и период.
- Настройки (U.13): профиль с API, темы (persist), уведомления persist через API, выход.
- Уведомления (U.14/F.11): колокол с бейджем + панель. Сервер отдаёт только настройки напоминаний, поэтому предстоящие события (24 ч), близкие сроки (24 ч) и просрочки выводятся из загруженных сущностей с учётом настроек. Push — только при появлении мобильного клиента (по ТЗ).
- Сообщения (U.15/F.12–F.14, U.3): тосты успеха/ошибки, понятные тексты + рекомендации (включая таймаут 12 c — клиентский страж R.1).
- Русский UI (U.5), confirm-диалог вместо `window.confirm`, фокус в модалках, `prefers-reduced-motion`.

## Адаптив (U.4)

- `<900px`: мобильная phone-верстка с нижним таб-баром (5 вкладок).
- `≥900px`: широкий layout в том же дизайне — sidebar с подписями, topbar (дата, колокол, профиль), контент до 1280px, сетки (Главная 2 колонки), модалки по центру.

## Запуск

```bash
cp .env.example .env   # VITE_API_URL=http://localhost:8080/api/v1
npm install
npm run dev            # http://localhost:5173
npm run build
```

Backend CORS уже разрешает `http://localhost:5173` (см. корневой `.env` → `CORS_ALLOWED_ORIGINS`).
Docker: `docker compose up frontend` (`:3000` → nginx со сборкой).

## Deploy-заметки (ТЗ S.4/R.5, вне кода)

- S.4 HTTPS: терминировать TLS на reverse proxy (nginx/Caddy) перед backend и frontend; затем выставить `SECURE_REFRESH_COOKIE=true`.
- R.5/R.4 бэкапы: `pg_dump` по cron ≥1 раза в сутки + проверка восстановления; данные переживают рестарт в `postgres_data` volume.
