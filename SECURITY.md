# Сообщения об уязвимостях

Не публикуйте токены, пароли, содержимое `.env`, данные аккаунтов и воспроизводимый доступ к чужим данным в открытом issue.

Используйте приватное сообщение через [GitHub Security Advisories](https://github.com/Aam-Shaegar/Rhythm/security/advisories/new), если функция доступна. Если она выключена, создайте issue с просьбой о приватном канале связи, без технических деталей уязвимости и секретов.

В сообщении укажите затронутую версию, условия воспроизведения, ожидаемое и фактическое поведение. Проверяйте на собственном локальном экземпляре.

`.env` не отслеживается Git, но удаление файла из текущей версии не удаляет его из старых коммитов. Ранее опубликованные действующие секреты следует отозвать и заменить; конфигурацию сервера хранить отдельно от репозитория.
